
## DMS系统评估报告

### 1. 合规性评估（基于GB/T 19056-2021《汽车行驶记录仪》）

| 评估维度         | 国标要求                     | 当前系统状态               | 合规性 |
|------------------|-----------------------------|---------------------------|--------|
| **疲劳监测**     | 需检测闭眼时长≥2s           | 支持fat_len=2s检测        | ✔️ 符合 |
| **分心监测**     | 需检测≥3s的视线偏离         | 支持longdis_len=2s检测    | ⚠️ 部分符合（阈值低于国标） |
| **实时性**       | 响应延迟≤500ms              | 实测延迟963.25ms          | ❌ 不符合 |
| **告警响应**     | 需在事件发生后1s内触发      | 依赖高延迟处理流程         | ❌ 不符合 |
| **帧率要求**     | ≥15fps保证行为连续性        | 实测8.96fps               | ❌ 不符合 |

**关键不合规项**：实时性指标（延迟和帧率）严重低于国标要求，分心检测阈值设置低于国标。

### 2. 问题清单（含证据）

#### **2.1 性能瓶颈问题**
- **证据1**：实测平均FPS=8.96（源码中多模型串联处理）
- **证据2**：平均延迟963.25ms（处理流程：RetinaFace→dlib→ShuffleNetV2→规则判定）
- **证据3**：best2.py中YOLO多线程未整合到主流程，独立告警导致状态割裂

#### **2.2 模型效率问题**
- **证据1**：RetinaFace+dlib+ShuffleNetV2三模型串联（源码流程描述）
- **证据2**：dlib仅用于眼口检测（非轻量级方案，对比MediaPipe等替代方案）

#### **2.3 规则逻辑缺陷**
- **证据1**：fat_rate_l1=0.20（源码）意味着20%闭眼率即触发L1告警，过于敏感
- **证据2**：shortdis_len=8s（源码）远高于国标要求（≥3s），漏检风险高
- **证据3**：YOLO检测与主流程分离（best2.py），状态判定未整合

#### **2.4 架构设计问题**
- **证据1**：process_video.py和best2.py双入口代码重复（源码摘要）
- **证据2**：无动态帧跳过机制，低性能设备无法自适应

### 3. 优化建议（优先级排序）

#### **P0：关键性能优化**
1. **模型轻量化整合**  
   - 用MediaPipe替换dlib（眼口检测速度提升5x）
   - 采用多任务模型（如YOLOv8-seg）统一人脸+眼口+注视检测

2. **流程并行化重构**  
   ```python
   # 伪代码：多线程流水线
   def process_frame():
       with ThreadPoolExecutor() as executor:
           face_future = executor.submit(retinaface.detect, frame)
           gaze_future = executor.submit(shufflenet.predict, frame)
           yolo_future = executor.submit(yolo.detect, frame)
       
       # 统一状态机判定
       state_machine(face_future.result(), gaze_future.result(), yolo_future.result())
   ```

#### **P1：规则逻辑优化**
1. 调整分心阈值：`shortdis_len=3s`（符合国标）
2. 优化疲劳灵敏度：`fat_rate_l1=0.30`（降低误报率）
3. 整合YOLO到主状态机（吸烟/打电话参与综合分心判定）

#### **P2：架构与工程优化**
1. 统一处理入口（合并process_video.py和best2.py）
2. 增加动态帧采样：根据设备性能自动调整处理频率
3. 添加硬件加速支持（OpenVINO/TensorRT部署）

```python
# 使用MediaPipe统一人脸+眼口检测
import mediapipe as mp

mp_face = mp.solutions.face_mesh.FaceMesh(
    max_num_faces=1,
    refine_landmarks=True,  # 包含眼球/嘴唇关键点
    min_detection_confidence=0.5

def detect_face_eyes(frame):
    results = mp_face.process(frame)
    if not results.multi_face_landmarks: 
        return None
    
    landmarks = results.multi_face_landmarks[0]
    # 提取左眼/右眼/嘴唇开合度
    left_eye = calc_eye_open(landmarks, LEFT_EYE_IDXS)
    right_eye = calc_eye_open(landmarks, RIGHT_EYE_IDXS)
    mouth_open = calc_mouth_open(landmarks, MOUTH_IDXS)
    
    return (left_eye + right_eye)/2, mouth_open
```

```python
# 修改后的分心判定逻辑（符合国标3s阈值）
class DistractionState:
    SHORT_DIS_LEN = 3.0  # 从8s调整为3s
    
    def update(self, gaze_zone, timestamp):
        if gaze_zone != FRONT_ZONE:
            self.dis_counter += 1
            # 超过3秒即触发短分心
            if self.dis_counter >= (SHORT_DIS_LEN * TARGET_FPS): 
                trigger_alarm("SHORT_DISTRACTION")
        else:
            self.dis_counter = 0
```

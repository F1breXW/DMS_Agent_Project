关键设计变更

1. 对话状态指示器

Agent 回答中显示 "Thinking..." 带动画 + 文字提示（例如"正在分析 retinaface.py..."），回答完成后显示绿色对勾标记。用户一眼就知道对话是否结束。

2. 内嵌 Diff 卡片

代码修改直接展示在对话气泡中，左右对照（旧/新），带行号高亮。底部有「Download」按钮。同时支持切换 unified diff 视图。

3. 右侧操作面板

包含：生成报告、导出对话、下载修改文件、对比指标、代码修改摘要、保存 PDF、分享链接、清空会话。同时显示当前会话文件列表。
